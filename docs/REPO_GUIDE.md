# Repo guide: what is where (2026-11-12 UTC)

LIVE = the rain-hedging project (docs/SPEC_v3.md, Phases 0-4). EARLIER = the temperature study that preceded the
pivot (docs/SPEC.md, SPEC_v2.md), kept for the comparison section. The lead decides what moves to `archive/`;
file-level detail is in docs/ARCHIVE_NOTE.md. Start with README.md, then docs/SPEC_v3.md, docs/PHASE2_PREREG.md,
results/phase2/summary.md.
